Sorting Algorithms in Java

This folder contains implementations of sorting algorithms in Java as part of my DSA practice.

Algorithms

- Bubble Sort — sorts elements by repeatedly swapping adjacent elements.
- Insertion Sort — inserts each element into its correct position.
- Merge Sort — uses the divide-and-conquer approach.
- Quick Sort — partitions an array around a pivot.
- Selection Sort — repeatedly selects the minimum element.
- Counting Sort (Basic) — sorts elements using frequency counts.
- Stable Counting Sort — preserves the relative order of elements with equal keys.

Counting Sort: Basic vs Stable

Feature| Basic| Stable
Frequency counting| Yes| Yes
Preserves equal-key order| Not guaranteed| Yes
Time complexity| O(n + k)| O(n + k)

Here, "n" is the number of elements and "k" is the key range.
